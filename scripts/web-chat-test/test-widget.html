Fake customer website

This page simulates a tenant's own site (a different "origin" than the app). The floating chat launcher in the bottom-right is injected by widget.js. Click it to open the AI chat in an iframe.

  1. Run the app: npm run dev (http://localhost:3000).
  2. In /dashboard/chatbot, enable the widget and copy your data-chat-key, then paste it below (or use the seeded key).
  3. Open this file over HTTP so the origin isn't null:
    npx serve scripts/web-chat-test — then visit the printed URL (e.g. http://localhost:3000 is the app; serve picks another port). Opening via file:// also works because the default allow-list is empty (any origin).
